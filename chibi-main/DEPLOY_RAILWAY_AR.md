# تنصيب بوت Chibi على Railway

## الخطوات

1. **ارفع المشروع على GitHub**
   - أنشئ Repository جديد وارفع محتوى هذا المجلد بالكامل.

2. **أنشئ مشروع على Railway**
   - اذهب إلى https://railway.app → New Project → Deploy from GitHub Repo
   - اختر الريبو الذي رفعته.
   - Railway سيكتشف `railway.json` و `Dockerfile` تلقائيًا ويبني الصورة.

3. **أضف متغيرات البيئة**
   - افتح تبويب Variables في خدمة المشروع.
   - انسخ المتغيرات من ملف `.env.example` وعبّها بقيمك الحقيقية:
     - `TELEGRAM_BOT_TOKEN` (من @BotFather) — إلزامي
     - مفتاح واحد على الأقل من مزودي الذكاء الاصطناعي (OpenAI, Anthropic, Gemini...)

4. **أضف Volume للبيانات**
   - في تبويب Settings → Volumes → أنشئ Volume واربطه بالمسار `/app/data`
   - هذا يحافظ على بيانات المحادثات والذاكرة بعد كل إعادة نشر.

5. **Deploy**
   - اضغط Deploy، انتظر اكتمال البناء (قد يأخذ عدة دقائق بسبب تحميل نموذج التضمين embeddings).
   - بعد نجاح البناء البوت يعمل تلقائيًا كخدمة خلفية — لا حاجة لفتح بورت.

## طريقة بديلة عبر Railway CLI (بدون GitHub)

```bash
npm install -g @railway/cli
railway login
cd chibi-main
railway init
railway up
```
ثم أضف المتغيرات من لوحة Railway كما بالخطوة 3.

## ملاحظات
- تأكد إن `TELEGRAM_BOT_TOKEN` صحيح وإلا البوت ما راح يتصل.
- إذا ما ضفت مفتاح أي مزود ذكاء اصطناعي، البوت لن يستطيع الرد على الرسائل.

## قائمة أزرار عربية
تم تعديل `chibi/runners/telegram.py` بحيث يظهر للمستخدم لوحة أزرار عربية ثابتة أسفل الشاشة بدل الاعتماد على أوامر `/` فقط:

- ❓ المساعدة
- 🔄 إعادة تعيين المحادثة
- 🧵 محادثة جديدة
- 🗑️ حذف المحادثة الحالية
- 🖼️ توليد صورة
- 🎨 اختيار نموذج الصور
- 🤖 اختيار نموذج الذكاء الاصطناعي
- 🔑 تعيين مفتاح API
- ⛔ إيقاف

تظهر اللوحة تلقائيًا عند إرسال `/start`. أوامر `/` القديمة (مثل `/reset`, `/help`) ما زالت تعمل بالخلفية لمن يفضّل كتابتها، لكن الأزرار هي الطريقة الأساسية الآن.
